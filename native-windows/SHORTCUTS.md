# Shortcuts — Famidash Editor (concise)

## Global / File
- Ctrl+N — New TMX
- Ctrl+O — Open TMX
- Ctrl+S — Save
- Ctrl+Shift+S — Save As
- Ctrl+W — Close tab
- F1 — Set Options
- F5 — Open Simulator

## Undo / Clipboard
- Ctrl+Z — Undo
- Ctrl+Shift+Z or Ctrl+Y — Redo
- Ctrl+X — Cut
- Ctrl+C — Copy
- Ctrl+V — Paste

## Tools (single-key)
- B / P — Place/Brush
- M — Move
- E — Erase
- F — Fill
- S — Select
- L — Lasso select
- W — Magic Wand
- T — Structure

## Selection (mouse + modifiers)
- Ctrl+Click — Toggle selection of a tile/sprite
- Ctrl+A — Select all (respects active layers)
- Esc — Deselect all / cancel polygon
- Rectangle drag (left-drag) — select area; hold Ctrl while completing to add to existing selection
- Lasso select — hold Ctrl when completing to add to existing selection
- Magic Wand — hold Ctrl to add found region to selection

## Manipulate (selection actions)
- Manipulate menu: Rotate 90° CW, Rotate 90° CCW, Resize (hover → click+drag), Flip Horizontal, Flip Vertical

## Navigation / View
- Left / Right — coarse horizontal scroll
- Shift + Left / Right — fine continuous horizontal scroll while held
- Ctrl + Mouse wheel — zoom (0.25 increments)
- Middle mouse drag — pan

## Layers / Palette
- 1 / NumPad1 — Tiles layer
- 2 / NumPad2 — Sprites layer
- 3 / NumPad3 — Both layers
- Click `Tiles` / `Sprites` labels to toggle/activate; Ctrl+Click toggles without affecting the other

## Editing
- Delete — Erase selection on active layers

## Simulator (when focused)
- Up / Down — movement input (held)
- X — action/jump (edge-triggered)
- W — invert gravity / toggle behavior
- F2 — Toggle sprite hitboxes
- Shift+F12 — Toggle Y-velocity overlay
- - (OemMinus / Subtract) — Decrease sim speed by 10%
- + (OemPlus / Add) — Increase sim speed by 10%
- Tab — Adjust tab-speed multiplier (modifiers change multiplier)
- Esc — Toggle pause/unpause
